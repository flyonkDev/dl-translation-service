# Покрытие верификации водительских прав (OCR + эвристики)

Документ для команды: **что уже настроено осознанно**, а что пока опирается на общие правила по умолчанию. Обновляйте вручную при добавлении страны или после QA на реальных образцах.

## Как устроено в коде

- **OCR (Optical Character Recognition):** Tesseract.js, цепочки языков по стране — `src/verify/data/ocr-languages.ts`, нормализация кода страны — `src/verify/country-registry.ts`.
- **Текстовые маркеры:** `src/verify/data/keywords-by-country.ts`.
- **Лимит попыток OCR:** переменная окружения `VERIFY_OCR_MAX_ATTEMPTS` (по умолчанию 6).

## Важно для маркетинга и поддержки

Верификация даёт **сигнал качества загрузки и распознавания**, а не проверку подлинности документа в реестре государства. Для стран без строки в таблице всё равно может сработать общий набор правил (`eng` + fallback), но **ожидания нужно формулировать осторожно**, пока строка не переведена хотя бы в «smoke».

## Логи для аналитики

В логах бэкенда ищите JSON-строки с полем `evt: "verify_metrics"`: страна, список попыток OCR, выбранный язык, уверенность, score, статус. Сырой распознанный текст в эти логи **не пишется**.
